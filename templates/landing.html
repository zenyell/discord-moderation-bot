Mask comes with a built-in control panel. Configure every feature without touching a single line of code.

Live Dashboard

See Mask's status, server stats, and recent activity at a glance. Real-time updates with no refresh needed.

Moderation

Ban, kick, mute, and warn members. View full moderation history and manage active cases from one page.

Logging

Track message edits, deletes, voice events, and member joins. Route each event type to a dedicated channel.

Greetings

Set a warm welcome message and farewell message with dynamic placeholders like {mention}, {server}, and {count}.

Auto & Reaction Roles

Assign roles automatically on join, or let members self-assign by reacting to a message — fully configurable.

User Lookup

Search any member to view their profile, join history, roles, and full moderation log in seconds.
